# Licentivo Launch 0.3.9 Beta

Release date: 2026-11-06 (Asia/Shanghai).

This server release fixes refund authorization synchronization and delayed
security emails, and makes expiry-reminder database coverage mandatory in the
standard MySQL test runner.

- Order refund and reversal snapshots by entitlement version, so a clock
  difference between Launch and MySQL cannot leave revoked access blocked behind
  an older synchronization task. Older positive snapshots and license migration
  safeguards keep their existing ordering rules.
- Cancel expired, consumed or superseded verification, password-reset and
  email-change messages before SMTP quota is reserved. Previously queued messages
  are checked as well; credential validity is never extended.
- Run expiry-reminder database, HTTP permission and quota tests from
  `scripts/test-mysql.ps1`, and fail the runner if required suites are missing or
  skipped.

## Upgrade

Replace the server executable and keep your existing configuration, master key,
database and uploaded files. This release adds no database migration. Existing
queued refund snapshots and security emails use the corrected checks.

Launch client packages remain at 0.1.8, with the embedded official Licentivo SDK
at 0.11.8. Client package publication is unchanged.

## Validation

The authorized remote MySQL 8.4.11 regression and the local standard MySQL 8.4.13
runner each passed 380 test nodes with no failures. Required expiry-reminder and
security-email suites ran successfully. The independent product-upload test
requires separate end-to-end configuration and was skipped. Frontend logic
passed 78 tests; Go static checks and the Windows server build also passed.

See the [fix and regression record](../integration-fixes-2026-11-06.md) for the
reproducing tests, final results and temporary-database cleanup verification.
