# Licentivo Launch 0.3.11 Beta

Released on 2026-11-24.

Launch 0.3.11 Beta updates the integration instructions and bundled client sources to Launch SDK 0.1.10 with Licentivo SDK 0.11.9. Native C and C++ consumers can discover the embedded Licentivo package with CMake. The exported CMake configuration reads the required upstream version from the embedded SDK's VERSION file. The Java example's compiler diagnostics now point to the embedded SDK sources and the required JDK.

## Upgrade

Download the package for your operating system and processor and verify its SHA-256 digest. Replace the Launch binary while keeping your configuration, master key, database and uploaded files. Run `launch version` to confirm `0.3.11-beta`. Existing storefronts require no schema migration for this patch.

Client developers can use the [Launch SDK 0.1.10 release](https://github.com/spf86/licentivo-launch-sdk/releases/tag/v0.1.10). See the [SDK compatibility guide](../sdk-compatibility.md) for the matching backend and the [0.3.10 Beta release notes](v0.3.10-beta.md) for the checkout, backup and storefront fixes included in this release.
