# Licentivo Launch 0.3.8 Beta

Release date: 2026-11-06 (Asia/Shanghai).

This server release improves the localized storefront, customer portal and
application integration screens.

- Add bundled interface catalogs and fourteen language choices for functional
  storefront, purchase, account and integration screens. Arabic and Urdu use RTL
  layout, while code and explicitly English AI instructions remain LTR.
- Keep the requested interface language when merchant content falls back to its
  original language. Show an accurate original-content notice rather than
  suggesting a translation is being generated.
- Preserve sandbox preview and product routes when changing languages, and
  clear stale interface-language query overrides when returning to native routes.
- Translate integration checks, generated-code copy states and license delivery
  controls without translating merchant-authored names or generated code.
- Correct localized purchase durations and parameterized device-release quotas.

See [interface languages](../interface-localization.md) for the boundary between
fixed interface text and merchant-authored content.

## Upgrade

Replace the server executable and keep your existing configuration, master key,
database and uploaded files. Interface catalogs are embedded in the executable;
no separate frontend installation or translation-service credential is needed
for fixed interface text. This release does not add a database migration.

Launch client packages remain at 0.1.8, with the embedded official Licentivo SDK
at 0.11.8. The licensing protocol and client package publication are unchanged.

## Validation

Release checks cover interface catalog placeholders, language persistence,
merchant-value preservation, public routing, integration code and prompt output,
existing application tests, and Windows/Linux release packages for amd64/arm64.
