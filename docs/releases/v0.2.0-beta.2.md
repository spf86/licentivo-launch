# Licentivo Launch v0.2.0-beta.2

This development beta updates the self-hosted storefront, payment providers, application integration and installation workflow. It replaces the beta.1 local-development JSON setup with a release-package-first `config.yaml` flow.

`SHA256SUMS.txt` covers all four archives. Each archive contains the executable, installation guide, public YAML example, version/build information, MIT license and dependency notices. Running a package requires MySQL 8.0.16+; Go, Git, Node.js and a compiler are not required.

## Installation

1. Extract the package and open a terminal in the extracted directory.
2. Run `./launch.exe init` on Windows or `./launch init` on Linux.
3. Edit the generated `config.yaml`, set `database_dsn`, and preserve its generated `master_key`.
4. Run `./launch.exe serve` or `./launch serve`.
5. Open `http://localhost:18080/#/login`, sign in with `admin@example.com` / `LaunchAdmin123!`, and replace the initial password.

`init` refuses to overwrite existing configuration. Subsequent starts use `serve` directly. Keep `config.yaml`, `.local`, the original master key, MySQL data and uploaded files during upgrades.

## Changes since beta.1

- Release packages now use root `config.yaml`, `launch init` and `launch serve`; `--config PATH` supports service deployments. The former `dev` command remains a compatibility alias.
- Added Stripe, PayPal, Waffo and Paddle payment configuration and related purchase/refund handling.
- Added Resend or generic SMTP registration/email settings, optional verification and updated administration workflows.
- Added the application integration workspace with validated public configuration, direct connection code and local English AI prompts.
- Added versioned Launch client packages for Go, Python, C#, Java, JavaScript, Rust, Ruby, C and C++. Client v0.1.1 embeds official Licentivo SDK v0.11.0 and requires no separate official SDK installation.
- Added account login, session restoration, protected feature execution, logout, close and explicit device-release guidance and examples.
- Added encrypted backup/restore recovery configuration using `PATH.secrets.yaml`, operational checks and updated deployment documentation.
- Refined storefront, administration navigation, payment settings and responsive interface behavior.

## Verification and limits

Go tests and vet, JavaScript prompt/state tests, release archive checks and isolated MySQL integration checks cover the implemented local behavior. The Windows amd64 binary is smoke-tested natively. Windows ARM64 and Linux amd64/ARM64 are cross-built with CGO disabled; target-native acceptance is still deployment-specific.

Public client-package installation was verified separately for all nine languages. Real merchant payment, email, translation, licensing and production deployment acceptance still requires configured external accounts and remains outside local build evidence. Live-sales gates remain in place.
