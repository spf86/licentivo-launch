# Licentivo Launch 0.3.6-beta

Release date: 2026-11-01. Paired with Launch SDK 0.1.8 and Licentivo SDK 0.11.8.

- Add complete customer-order and merchant-customer pagination, server totals,
  search and filters so records beyond the first 100 remain accessible.
- Render account/admin pages immediately after login even when the URL hash
  does not change, and describe missing translations accurately.
- Show authorization connections and their release scope clearly. Multiple
  floating instances on one computer remain separate connections.
- Preserve device-operation idempotency conflicts and request identifiers
  instead of reporting them as temporary licensing failures.
- Update all nine managed SDKs with Application metered execution, explicit
  settlement, original-reservation renewal and durable recovery. Include Python
  fork safety and Launch floating authorization compatibility.

Deploy the matching Licentivo backend before applications using the new
floating-account or reservation-renewal behavior. Back up the merchant and
licensing databases and configuration before upgrading. Install rebuilt SDK
and native packages; older packages with the previous version do not contain
these fixes. Existing unknown task outcomes require checking durable business
results before explicit settlement; expired reservations remain expired.

The release retains the account-identity exchange flow and self-hosted MIT
license. Merchant administration remains Simplified Chinese; storefronts
retain their existing ten-language support. External payment settlement,
provider refunds, email delivery and translation-provider delivery are separate
integration checks and are not claimed by the SDK regression results.

See the current [metered execution and recovery guide](https://github.com/spf86/licentivo-launch-sdk/blob/main/docs/metered-feature-tasks.md) for the paired SDK's nine-language API and long-task limits.
