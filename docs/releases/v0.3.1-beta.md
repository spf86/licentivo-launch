# Licentivo Launch 0.3.1-beta

This beta updates the merchant server, client integrations and purchase-to-license reconciliation.

- Deliver restrictive entitlement updates independently of unresolved positive synchronization, with explicit downgrade snapshots for the matching Licentivo server.
- Correct renewal recovery, full-coverage upgrade quotes, refunds, reversals, plan mapping and affected purchase synchronization paths.
- Add durable login-session revocation delivery and strengthen account, product and environment boundaries.
- Improve large translation batches and external-provider error handling.
- Update the nine-language Launch SDK integration to 0.1.3 with reviewed Licentivo SDK 0.11.2, including logout persistence, stale-instance cache isolation and old-login binding protection.

Release artifacts contain Windows and Linux builds for amd64 and arm64, installation instructions, source archives and SHA-256 checksums. Existing configuration, master keys, uploads and MySQL data must be preserved when upgrading.

Licentivo remains the authority for device bindings, features, limits, signed grants and runtime verification. This beta does not replace deployment-specific payment, email and production acceptance checks.
