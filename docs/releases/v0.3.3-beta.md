# Licentivo Launch 0.3.3-beta

This release updates account and entitlement recovery, storefront policies and the managed application SDKs.

- Keep account login, logout, cancellation and callbacks consistent across the Go, Python, C#, Java, JavaScript, Rust, Ruby, C and C++ adapters.
- Correct purchase, refund and delivery synchronization and preserve errors returned by the licensing service.
- Support explicitly enabled local HTTP testing with consistent origin validation. Production connections retain their HTTPS configuration.
- Include store policy editing and HTTP testing documentation in 14 languages.
- Update Launch SDK to 0.1.5 and embed Licentivo SDK 0.11.5, including durable logout, offline authorization and restart recovery fixes.

Back up the database and preserve the configuration, master key, uploads and data before replacing the executable. Continue using `serve` with the existing configuration. Verify downloads using `SHA256SUMS.txt`.
