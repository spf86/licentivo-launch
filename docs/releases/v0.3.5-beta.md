# Licentivo Launch 0.3.5-beta

Bundles Launch SDK 0.1.7 with the reviewed Licentivo SDK 0.11.7 in all nine
languages. Device names and optional system and hardware details are passed to
the matching Licentivo backend without changing device identity or authorization
rules. Java supports an omitted device name, and native bindings include the
complete device-information implementation and Windows portability fix.

Existing account recovery, session ownership, logout retry and storefront
behavior are preserved. Launch remains free, MIT-licensed and self-hosted.
The merchant administration interface remains Simplified Chinese; the official
website labels its proposed English interface as a design preview. Storefronts
retain their existing ten-language support.
