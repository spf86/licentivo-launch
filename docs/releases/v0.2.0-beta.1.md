# Licentivo Launch v0.2.0-beta.1

A self-hosted software storefront, customer account portal, and purchase-to-license integration for [Licentivo](https://www.licentivo.com/), built with Go, GORM, MySQL, and an embedded website. This is the first downloadable development beta.

## Installation

1. Extract the matching archive and open a terminal in its directory.
2. Run `./launch.exe init` on Windows or `./launch init` on Linux. This creates `.local/dev/launch-config.json` and generates the instance master key.
3. Set `LAUNCH_DATABASE_DSN` in `.local/dev/launch-config.json` to your empty MySQL database.
4. Run `./launch.exe dev` or `./launch dev`.
5. Open **http://localhost:18080/#/login** and sign in with **`admin@example.com` / `LaunchAdmin123!`**.
6. Change the initial password when prompted, then sign in again. Administration is unlocked after the change.

The initial account is created only for an uninitialized database. Restarts and upgrades never replace an existing administrator or reset a changed password. The backend blocks administration and desktop sessions until the initial password changes, and revokes old sessions when it is changed. Complete this local first-login step before publishing the site.

See the [English binary installation guide](https://github.com/spf86/licentivo-launch/blob/main/docs/binary-installation.md) for both architectures, configuration, checksum verification, and operation.

## Included capabilities

- Branded multi-product storefront, customer accounts, product documentation, policies, and platform-specific downloads.
- Stripe Checkout and PayPal payment/capture/refund adapters with verified events and a durable entitlement ledger.
- Licentivo product/policy mapping, automatic license issuance, renewals, upgrades, suspension, and device management.
- Durable jobs, stable request identifiers, retries, reconciliation, role permissions, and audit records.
- Resend account email, ten customer locales with DeepL content translation, optional managed HTTPS, safe CSV exports, and encrypted backup/restore.
- Official-SDK integration examples for C, C++, C#/.NET, Go, Python, and a trusted Web backend (available in the source repository).

This page records the beta.1 package as released. For the `config.yaml`, `launch serve`, nine-language client and expanded payment workflow, use [v0.3.0-beta](v0.3.0-beta.md).

## Verification and limits

Go tests and vet, JavaScript syntax, and isolated MySQL integration tests cover first account creation, concurrent startup, required password change, blocked access before that change, session invalidation, and restart preservation. Download archives are checked for target architecture, release version/build metadata, permitted contents, and checksums. Windows amd64 is smoke-tested natively.

Windows ARM64 and Linux amd64/ARM64 are cross-built with CGO disabled. Native runtime acceptance on those targets remains pending. Docker/Compose execution, real provider acceptance, full accessibility/performance, and production readiness are not claimed. Live-sales gates remain in place.

## Upgrades and data

Retain the original master key, private configuration, MySQL database, and uploaded files. Existing accounts continue to work. Back up before an upgrade because startup maintains the database schema.
