# Licentivo Launch 0.3.10 Beta

Released on 2026-11-24.

- Checkout retries and delayed provider responses preserve settled payments. A confirmed failed payment closes the pending order and clears its checkout link. Customers see issued or previously purchased products in their account.
- Editing brand text preserves the storefront's theme and logo. Sandbox previews retain the selected environment when customers navigate between products, documentation, downloads and account pages.
- Backup restore accepts archives created before document libraries existed. New backups record the number of tables so restore can detect incomplete archives.
- Docker Compose stores uploaded files on the persistent `launch-uploads` volume. The container can write uploads and temporary files with its unprivileged service account and read-only root filesystem.

## Upgrade

Back up the database and uploaded files before replacing the server binary. Keep the existing configuration and master key. Install the archive for your operating system and architecture, then run `launch version` to confirm `0.3.10-beta`. Compose installations should rebuild the image and preserve their upload volume. If you previously used a custom upload location, keep it mounted or migrate its contents before switching volumes.

The [installation guide](../installation.md) includes setup and upgrade instructions. See the [SDK compatibility matrix](../sdk-compatibility.md) for application integrations.
