# Licentivo Launch 0.3.7 Beta

Release date: 2026-11-05 (Asia/Shanghai).

This server release adds authorization expiry email reminders and site-wide mail budgets, and improves localized SEO and administration navigation.

- Check eligible live authorizations once per hour, with per-authorization inherit/on/off preferences and email language overrides in customer purchase details.
- Identify the product, purchased plan, and actual license policy in each reminder. Support ten template languages. Merchant contact and Reply-To are optional, explicitly configured fields; no portal button or inferred administrator contact is added.
- Configure one shared hourly/daily/monthly email budget in Email & registration. All customers and server instances share database-backed counters. Registration, password recovery and email changes take priority, followed by transactional/invoice mail, then reminders. Reminders cannot consume the protected reserve.
- Recheck consent, purchase coverage and recipient before delivery/retry; cancel obsolete reminders after renewal or opt-out. Failed SMTP attempts consume budget, while quota waiting does not consume a retry.
- Preserve independently configured language-specific homepage/product keywords, titles, descriptions and defaults in server-rendered HTML. Do not carry source-language text into other markets' defaults.
- Move system settings categories into an expandable sidebar group at the same level as Operations tools. Keep settings reachable through a selector on narrow screens.

## Upgrade

Back up the Launch database and master key before upgrading. Normal startup migrates the new reminder settings, preferences, scan coordination and shared quota counters. Existing installations start with automatic reminders disabled. Configure email budgets before enabling reminders.

See [reminder settings and accounting](../expiry-email-reminders.md), [administration API](../expiry-reminders-openapi.json), and [localized SEO](../seo-localization.md).

## Validation

Release checks use isolated MySQL databases and recording mail transports. They cover shared concurrent limits, hourly/daily/monthly reserves, account/transaction priority, reminder languages, renewed/disabled authorizations, settings permissions, backups, localized metadata, and server/browser regressions. Native external SMTP delivery and merchant-specific payment/licensing acceptance remain deployment-specific checks.

This publication changes the Launch server version only. Client package versions and publication records remain independent.
