# Licentivo Launch 0.3.4-beta

Updates the bundled Launch SDK to 0.1.6 and its reviewed Licentivo core to 0.11.6. The native core preserves macOS device identities when a runtime signal interrupts an OS pipe read, fixing intermittent Ruby initialization failures and the same shared C/C++/Rust path.

The integration prompts, install commands, package versions and embedded source checksums now identify the matching patch releases. The authorization protocol and database schema are unchanged.

Validation includes nine-language lifecycle regressions on Linux x64/ARM and macOS Intel/ARM, plus 500 stable Ruby initializations on each macOS architecture under GC pressure.
