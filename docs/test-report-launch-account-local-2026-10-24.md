# Launch 账号与购买期限改造：本地验证

日期：2026-10-24。修改范围为 Launch 和九种语言的 Launch SDK；未部署、未发布软件包，未提交或推送 Git。

## 已完成的边界

Launch 负责账号、商品、订单、支付、退款、续费与升级报价，以及绝对购买期限计算。购买结果通过 Licentivo 现有版本化快照接口同步，收到 `applied` 后才显示同步完成。

Licentivo 和官方 SDK 负责许可证、功能执行、设备绑定、授权会话、离线许可和撤销。Launch SDK 传递短期身份断言，停止获取和保存长期许可证密钥；显式退出调用官方 SDK 统一退出，保留网络失败时的退出日志。Launch 设备页代理远端列表、额度、绑定代次和处理结果。

Licentivo V39 新增的会话撤销 POST 和回执 GET 已接入。身份失效与通知入队使用同一事务，冻结连接和环境，按原事件恢复重试并保存各环境回执。账号范围通知待完成时暂停桌面登录；完成后要求真实认证时间严格晚于远端截止秒。网站恢复登录保持可用。
