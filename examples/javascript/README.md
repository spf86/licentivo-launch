# Node.js demo

From the repository root or matching source bundle, run `node examples/javascript/main.mjs launch-config.json product.json`. The Launch package includes official SDK 0.11.7; no separate SDK checkout or package is needed. This reference CLI accepts JSON inputs; new applications can copy the direct connection function from Launch without creating configuration files. Use `--help` for feature, secure remembered-login, logout and device-release options. This is a trusted Node/Electron-main-process example, not browser code. See [the package README](../../sdk/javascript/README.md) for the public 0.1.7 installation command, security boundaries and tests.
