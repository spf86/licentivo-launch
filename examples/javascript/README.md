# Node.js demo

From the repository root, run `node examples/javascript/main.mjs launch-config.json product.json`. Prepare the pinned SDK source with `./scripts/prepare-examples.ps1 -Source /path/to/official/sdk` first. Use `--help` for feature, secure remembered-login, logout and device-release options. This is a trusted Node/Electron-main-process example, not browser code. See [the package README](../../sdk/javascript/README.md) for security boundaries and tests.
