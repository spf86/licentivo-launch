# Ruby demo

From the repository root, run `ruby examples/ruby/main.rb launch-config.json product.json`. Install official `licentivo-sdk` 0.11.0 for your platform or build the prepared native source first. Use `--help` for secure remembered-login, protected features, logout and device-release options. See [the package README](../../sdk/ruby/README.md) for native prerequisites, cancellation semantics and tests.
