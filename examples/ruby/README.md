# Ruby demo

From the repository root or matching source bundle, run `ruby examples/ruby/main.rb launch-config.json product.json`. The Launch package includes official SDK 0.11.2 and its private native core; no separate official SDK gem is needed. Source builds still require the native toolchain described in the package README. This reference CLI accepts JSON inputs; new applications can copy the direct connection function from Launch without creating configuration files. Use `--help` for secure remembered-login, protected features, logout and device-release options. See [the package README](../../sdk/ruby/README.md) for the public 0.1.4 installation command, native prerequisites, cancellation semantics and tests.
