# Launch SDK 0.1.10

The installed CMake configuration now derives the required Licentivo version from the SDK bundled in the archive. C and C++ applications can load the matching package through `find_package(LicentivoLaunch CONFIG REQUIRED)` after moving the installation to another directory.

JavaScript and Python retain the pending device-logout retry fixes. The Rust API documentation includes a compiled account-login and feature-check example. The release pairs with Launch server 0.3.11-beta and embeds Licentivo SDK 0.11.9 across all nine languages.

Check the [registry status](../registry-status.json) before selecting a package-manager installation.
