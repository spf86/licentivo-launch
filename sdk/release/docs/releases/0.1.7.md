# Launch SDK 0.1.7

Updates the embedded Licentivo SDK to 0.11.7 for all nine languages. Applications
report readable device names and optional operating-system and hardware details
to the matching backend. These fields are for display, never licensing identity.

Includes optional Java device-name initialization and complete, portable native
sources for C, C++, Rust and Ruby. Account ownership, recovery and logout retry
behavior are preserved. Packages remain self-contained and MIT-licensed.
