# Launch SDK 0.1.8

Release date: 2026-11-01. Embeds Licentivo SDK 0.11.8 in all nine languages.
Use with Launch server 0.3.6-beta and the matching Licentivo backend.

- Expose metered execution and explicit known-result settlement through the
  Application API in Go, Python, C#, Java, JavaScript, Rust, Ruby, C and C++.
  The Application uses the official runtime created during account login;
  unsupported custom runtime adapters reject metered operations explicitly.
- Renew the original reservation during long business operations through the
  embedded SDK. Operation identity, quantity, task journals and pending
  settlement survive retry and account identity refresh.
- Include Python process/fork task locking and Launch floating-account
  authorization fixes from Licentivo SDK 0.11.8.
- Keep account recovery, instance ownership, logout retry and protected feature
  execution in the same managed runtime.

Install only the Launch package for the selected language. Keep a stable
operation ID, shared task-cache path and durable business output. After a
process dies during a callback, check the business outcome before calling the
explicit resolve method; retries must not repeat completed business work.
Python children must create a new Client after fork. JavaScript business
callbacks must keep the event loop responsive; use a worker for long CPU work.
Authorization expiry and the original UTC billing-period boundary still apply;
an expired reservation is not restored by this upgrade.

The nine-language lifecycle and metered API regressions, eight-language
long-task/recovery checks and embedded source hashes were reviewed. Native
C/C++/Rust/Ruby users must install rebuilt artifacts from this release.
