# Launch SDK 0.1.9

Use Launch SDK 0.1.9 with Launch server 0.3.10-beta. Each language package embeds Licentivo SDK 0.11.9.

The JavaScript and Python clients retry outstanding device logout work when the Launch session already records that device logout was requested. Cleanup can resume after a restart or temporary network failure. The JavaScript runtime adapter exposes an optional retry method that accepts an abort signal.

The Rust crate adds an integration example for account login and protected operations. The public API specification and SDK compatibility guide cover the matching server revision.

Check the [registry status](../registry-status.json) for availability of this exact version.
